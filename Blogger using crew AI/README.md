# 📝 Blogger using Crew AI 🚀

Welcome to **Blogger using Crew AI**!  
This project is a smart, collaborative blogging platform powered by AI and designed to streamline your content creation workflow.

---

## 🌟 Features

- 🤖 **AI-Powered Blogging**: Generate, edit, and enhance blog posts using Crew AI.
- 👥 **Collaborative Writing**: Multiple users can brainstorm and write together.
- 📝 **Rich Text Editor**: Write, format, and preview your posts with ease.
- 🔍 **Smart Suggestions**: Get topic ideas, outlines, and content improvements from the AI.
- 💾 **Save & Publish**: Easily save drafts or publish your blog posts.

---

## 🚀 Getting Started

1. **Clone the repo**  
   ```bash
   git clone https://github.com/Saranraj-k/QA-ChatBot.git
   cd QA-ChatBot/Blogger\ using\ crew\ AI
   ```

2. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   # Or follow the setup instructions for your environment
   ```

3. **Run the app**  
   ```bash
   python app.py
   # Or use the relevant command for your framework
   ```
